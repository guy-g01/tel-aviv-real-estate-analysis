# Data

The raw Tel Aviv real-estate transaction dataset is intentionally not stored in this repository.

The analysis expects the source file to be named:

`tel_aviv_real_estate.xlsx`

The source dataset contains 37,358 real-estate transactions from 2012–2017 and includes transaction price, property area, construction year, floor information and ITM coordinates (EPSG:2039).

Generated CSV/JSON datasets are also excluded from version control because they can be reproduced by running the notebook.
